ПОРТРЕТИ NPC ДЛЯ MEDIEVAL MERCHANT SIMULATOR v0.11

Як це працює
------------
Одна папка = одна й та сама людина/зовнішність на різних етапах життя.
Наприклад, усі картинки чоловіка, який проходить шлях від раба до
майстра-коваля, покладіть в папку:

assets/npc/male_01/

Для жіночого набору використовуйте:

assets/npc/female_01/

Формат зображень
----------------
- PNG
- Для картки: вертикальний портрет, співвідношення приблизно 11:13,
  наприклад 550x650 або 1100x1300 px
- Для особової справи: повноростове вертикальне зображення,
  рекомендовано приблизно 700x1300 або 1050x1950 px
- Назви файлів тільки малими латинськими літерами, як нижче

Обов'язкові базові файли в наборі
---------------------------------
slave.png       - NPC у статусі раба
serf.png        - NPC після переходу в кріпаки
citizen.png     - NPC після отримання статусу громадянина
free.png        - NPC, якого відразу найняли вільним працівником

Файли для майстрів
------------------
Додавайте лише ті спеціалізації, для яких маєте ілюстрації:

master_forge.png      - майстер-коваль
master_weaving.png    - майстер-ткач
master_stable.png     - майстер-стайничий / візник
master_kitchen.png    - майстер-кухар
master_inn.png        - майстер-корчмар у заїжджому дворі
master_warehouse.png  - майстер-комірник
master_guard.png      - майстер охорони / тренувальної зали

Повноростові файли для особової справи
---------------------------------------
Для кожної картинки, яку хочете показувати на окремій сторінці NPC,
додайте версію з префіксом full_:

full_slave.png             - повноростовий раб
full_serf.png              - повноростовий кріпак
full_citizen.png           - повноростовий громадянин
full_free.png              - повноростовий вільний працівник
full_master_forge.png      - повноростовий майстер-коваль
full_master_weaving.png    - повноростовий майстер-ткач
full_master_stable.png     - повноростовий майстер-стайничий
full_master_kitchen.png    - повноростовий майстер-кухар
full_master_inn.png        - повноростовий майстер-корчмар
full_master_warehouse.png  - повноростовий майстер-комірник
full_master_guard.png      - повноростовий майстер охорони

Резервні зображення
-------------------
Якщо спеціальне зображення майстра відсутнє, гра покаже citizen.png.
Якщо немає картинки потрібного статусу, гра спробує free.png, а далі
покаже стандартну іконку. Тому можна додавати арт поступово.

Для особової справи правило таке саме: якщо відповідного full_*.png
немає, гра спочатку спробує інший повноростовий резервний портрет,
а далі покаже звичайний портрет із картки NPC.

Як додати кілька зовнішностей
-----------------------------
Стартово гра використовує:
- male_01
- female_01

Якщо у вас є більше наборів, створіть, наприклад:
- assets/npc/male_02/
- assets/npc/female_02/

Після цього додайте назви папок у game.js у секції npcPortraitSets:

const npcPortraitSets = {
  male:["male_01","male_02"],
  female:["female_01","female_02"]
};

Нові NPC отримуватимуть одну з підключених зовнішностей випадково і
зберігатимуть її на всіх етапах розвитку.

Порада щодо вже існуючого збереження
------------------------------------
NPC, які вже створені у збереженні, отримають male_01 або female_01.
Щоб побачити різноманітні нові набори після їх підключення, почніть
нову гру або дочекайтесь прибуття нових кандидатів на ринок.
