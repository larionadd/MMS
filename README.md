# Medieval Merchant Simulator

A browser-based medieval trade and household simulator set in 1205 Europe.

## Play

Open `index.html` in a browser, or publish this folder with GitHub Pages.

## GitHub Pages

This is a static game. No build step is required:

1. Push the repository to GitHub.
2. Open repository settings.
3. Go to Pages.
4. Select `Deploy from a branch`.
5. Choose `main` and `/root`.

## Local Files

- `index.html` - game entry point
- `game.js` - game logic and localization
- `style.css` - visual styles
- `assets/` - images and sprite atlases
- `tests/smoke.test.mjs` - smoke test
